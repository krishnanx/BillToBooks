Put 5-10 photos of real (or realistic) handwritten Indian bills/receipts here,
named bill_01.jpg, bill_02.jpg, etc. Then fill in evaluation/ground_truth.csv
with the true vendor/date/amount/tax for each one by manually reading them.

Good sources if you don't have physical bills handy:
- Photograph a few real receipts you have (kirana store, auto-rickshaw, chemist).
- Ask friends/family for old handwritten bills.
- Search "handwritten receipt dataset" / "ICDAR SROIE" for public samples,
  but note SROIE is mostly printed receipts - the assignment wants handwritten
  ones, so a handful of real photos will make a much more honest evaluation.
